# Calculator Application using Method Overloading

A Java Calculator Application developed using Method Overloading, Encapsulation, and Object-Oriented Programming principles. The application performs arithmetic operations on different data types through overloaded methods.

## Objective

To understand Method Overloading and Encapsulation in Java while enhancing a calculator application using Object-Oriented Programming concepts.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Method Overloading
* Encapsulation using Private Variables
* Object-Oriented Design
* Console-Based Application

## Technologies Used

* Java
* IntelliJ IDEA
* OOP Concepts

## OOP Concepts Implemented

### Method Overloading

The same method name is used for different parameter types.

Example:

add(int a, int b)

add(double a, double b)

### Encapsulation

* Private data members
* Public getter and setter methods
* Controlled access to data

## Operations Supported

### Integer Addition

Input:
10 + 5

Output:
15

### Double Addition

Input:
10.5 + 5.5

Output:
16.0

### Subtraction

Input:
20 - 8

Output:
12

### Multiplication

Input:
6 * 7

Output:
42

### Division

Input:
20 / 5

Output:
4
